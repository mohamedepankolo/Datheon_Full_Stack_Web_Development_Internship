Making programme data useful

Context

Programme data can inform decisions only when collection is consistent and reporting is trusted.

Work and contribution

As a Data Manager, I worked on collection forms, spreadsheet-based cleaning and dashboards to help monitor programme performance.

What I learned

A simple reporting process that teams actually use is often more valuable than a complex dashboard that nobody maintains.

This is a personal project note, based on documented experience. Illustrative imagery is not a screenshot of the project.
