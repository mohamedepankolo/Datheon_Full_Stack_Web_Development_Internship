RECLIM / ANAM · Project note

Weather information in local languages

Context

Climate information is often available through technical forecasts that are not necessarily easy to understand for the communities who rely on them. The RECLIM work aims to make useful information accessible in local languages.

Work and contribution

My role focuses on application development, including how weather information can be presented clearly and how technical workflows can support local-language access. The application remains in testing, so its reach and impact are not yet established.

What I learned

One lesson from this work is that accessibility must be considered early in software design rather than added after development.

This is a personal project note, based on documented experience. Illustrative imagery is not a screenshot of the project.
