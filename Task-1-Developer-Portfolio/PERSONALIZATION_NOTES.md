# Adaptation notes

The original vCard template directory structure, navigation, pages, CSS, images, and JavaScript have been preserved. An isolated `assets/js/theme.js` and an appended CSS block provide an optional floating Light/Dark switch. Dark is the default.

The name, links, About, Resume, skills and project labels were adapted from Mohamede Pankolo’s CVs. Original template images remain **placeholders**; replace `assets/images/my-avatar.png`, project images, and blog images when you supply approved photos/screenshots. Project cards currently link to the GitHub profile rather than inventing project-specific URLs.

The blog is a set of potential writing topics, not claims of published articles. The template contact form uses a `mailto:` fallback and requires an email client; a backend form service is needed for reliable delivery.
